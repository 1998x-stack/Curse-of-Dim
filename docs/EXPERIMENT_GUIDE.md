# 实验手册：从高维几何到深度学习泛化

所有实验采用**合成数据 + 明确分布假设**。每组实验通过「研究问题 → 理论公式 → 受控变量 → 可视化 → 反例」建立可证伪的理解。

## 实验 01：空间覆盖与边界
- **数学**：每个坐标划分 10 格，网格总数为 10^d；各坐标位于中央80%区间的体积占比为 0.8^d。
- **严谨性**：最近邻 L∞ 半径在周期单位立方体（torus）计算，P(R_min>r) = [1-(2r)^d]^n，0<=r<=0.5。
- **看图**：固定网格稀疏性、中心体积衰减、为包含近邻必须扩大的半径。
- **限制**：有低维流形的数据不必填满整个 d 维网格。

## 实验 02：距离集中
- **假设**：X,Y 独立均匀分布在 [0,1]^d。
- **平方距离**：E[||X-Y||²]=d/6，Var[||X-Y||²]=7d/180。
- **delta 方法**：CV(||X-Y||)≈sqrt(7/(20d))，这是渐近近似，不是所有 d 的严格恒等式。
- **看图**：归一化距离分布、CV 实验值与理论近似、固定数据库大小时最近/最远距离比。
- **限制**：结论不是「距离随维度减小」，而是「相对差异缩小」。

## 实验 03：KNN + 无关特征
- **标签机制**：y=1[x1+x2>0]，另设5%独立标签翻转，独立同分布训练和测试。
- **只改变**：增加 d-2 个无关噪声坐标；训练数据和标签机制不随 d 变化。
- **控制组**：原始 KNN、只保留真实两维的 KNN、训练集 SelectKBest(2)+KNN、逻辑回归。
- **看图**：分类准确率以及64维决策函数的**条件二维截面**（其他坐标固定）。
- **误区**：条件切片不是整个高维分类器的边际决策边界。

## 实验 04：样本复杂度
- **函数**：f(x)=sqrt(2/d)*sum_i sin(2*pi*x_i)，控制信号尺度。
- **模型**：无标签噪声的 1-NN 回归；训练数量为 50 到 2700。
- **看图**：样本量不同的 log-log 测试 MSE 曲线及热力图。
- **限制**：不能把无噪声的 1-NN 直接当作有噪声非参数估计的最优收敛率。

## 实验 05：表示维度 vs 内在维度
- **潜变量**：z∈R²、x=Qz+σε∈R¹²⁸、Q.T Q=I。
- **核心严格性质**：当 σ=0，||Qz_i-Qz_j||=||z_i-z_j||；所有欧氏距离和近邻排序完全不变。
- **控制组**：原始高维 KNN、PCA 降到2维+KNN、已知 z 的 oracle KNN。
- **看图**：不同环境噪声下的测试 MSE 及协方差谱。
- **限制**：PCA 适合线性低秩，不能假定任意真实 embedding 恰为低秩线性流形。

## 实验 06：Double Descent
- **模型**：110 个高斯样本，真实信号只在前5维；其余维度独立噪声。
- **对照**：最小范数最小二乘（min-norm）和 Ridge；3次不同随机种子取中位数。
- **看图**：d/n 接近1时，测试 MSE 的插值峰值；训练误差和测试误差区别。
- **限制**：现象依赖数据分布、噪声和学习器，并非所有网络必然双降。

## 实验 07：病态优化≠维度灾难
- **仅2维**，缩小第二个特征的标准差并构建严重病态 Hessian。
- **数学**：H=X.T X/n，κ(H)=λ_max/λ_min。
- **对照**：原始梯度下降和按特征列标准差归一化后的梯度下降。
- **看图**：loss 下降、慢方向系数恢复、二维等高线和梯度路径。
- **结论**：二维照样可以病态；高维和优化难度没有简单单调对应关系。

## 学习路径与复现检查
1. geometry → distances：用几何和概率解释空间、近邻、距离。
2. knn_noise → sample_complexity → intrinsic_dimension：讨论无关坐标、样本量和任务结构。
3. double_descent → conditioning：区分参数维度、泛化与优化条件数。

每次进阶实验**只修改一个变量**；保存种子、样本量、模型参数以及指标 JSON。
